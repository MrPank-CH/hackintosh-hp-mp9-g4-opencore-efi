Notes：

Before use, replace the serial number, MLB, and UUID.
For proper display functionality, plug the monitor into the machine before booting so that normal use and hot-plugging work. Ports that were not connected before boot may not support hot-plugging.
Front-panel audio output does not support automatic detection; it can be enabled via manual switching. The headphone channel supports automatic detection.
